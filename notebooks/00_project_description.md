# 00. Описание проекта: CRM-аналитика онлайн-школы

---

## 1. Бизнес-модель

**Компания:** онлайн-школа IT-профессий (Digital Marketing, UX/UI Design, Web Development и др.). Обучение проходит полностью онлайн, основная клиентская база — Германия.

**Модель дохода:** B2C, разовый платёж или в рассрочку за курс (первый платёж клиента = `initial_amount_paid`). Полная стоимость курса - Offer Total Amount

**Воронка привлечения:**

Рекламный кабинет (Spend)
    ↓  клики
Заявка в CRM → Контакт (Contacts)
    ↓  квалификация
Сделка (Deals): Лид → Active Sales → Won/Paid / Lost
    ↑
Отдел продаж (звонки через Calls)


**Ключевые участники:**
- **Маркетинг** — управляет каналами (Google Ads, Facebook, TikTok, SMM, Webinar и др.), отвечает за UAL (уникальные заявки/лиды) и CPL (стоимость лида)
- **Отдел продаж** — менеджеры обрабатывают лиды, их эффективность замеряется через SLA (время первого ответа), конверсию лид→покупатель (C1) и Доход
- **Продукт** — линейка курсов, определяет оффер и продолжительность курса

**Назначение:** справочник лидов — каждый уникальный человек, обратившийся в школу.

| Поле | Описание | Проблемы и решение |

## 3. Критерии очистки

### 3.1 Принципы принятия решений

| Принцип | Описание |
|---------|----------|
| **Удаление** | Только полные содержательные дубликаты (100% совпадение всех значимых полей) |
| **Заполнение Known** | Backfill по связанному контакту (`contact_id`), если данные есть в другой сделке того же клиента |
| **Заполнение Unknown** | Категориальные поля без данных — `'Unknown'`, не NaN, чтобы записи не терялись при группировке |
| **Оставить NaN** | Числовые/датовые поля, где отсутствие = бизнес-факт (сделка не закрыта, платежа нет) |
| **Аномалии** | Сохраняются как есть, если они несут аналитическую ценность |

## 4. Модель юнит-экономики

### 4.1 Ключевые метрики

    CM (Маржинальная прибыль) 
    Revenue
    AC 
    UA   - количество уникальных заявок/лидов 
    C1   - конверсия лид → покупатель
    B    - количество покупателей
    AOV  - средний чек
    CAC  - стоимость привлечения одного покупателя
    CPA  - стоимость привлечения одного лида
    LTV  - выручка на лид (в данной модели ≈ AOV, без повторных покупок)
    LTC  - затраты на лид
    ROMI  - эффективность расходов на маркетинг
    LTV/CAC  — индикатор здоровья: норма > 3
